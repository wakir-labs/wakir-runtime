# tests/

Test suite for the Wakir Runtime. Tests for the WAT module live
here even though the module itself is BSL-licensed; the test code
is Apache-2.0 so that downstream adopters can use the same test
vectors against their own implementations once the module's
four-year auto-conversion to Apache 2.0 fires.

Code in this directory is licensed under Apache License 2.0
(see [../LICENSE](../LICENSE)).

Phase 1a, day 1: directory created. Concrete test files (Bitcoin
Merkle test vectors, RFC 8785 JCS vectors, WAT smoke fixtures)
land in later days.
